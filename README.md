# Telegram Bot — Сдача номеров

Полнофункциональный Telegram-бот на aiogram 3 + aiosqlite.

Пользователи сдают номера телефонов, администраторы проверяют их, начисляют баланс и обрабатывают выводы.

## Возможности

### Для пользователей
- Сдача номера (+7XXXXXXXXXX)
- История своих заявок
- Личный кабинет с балансом и статистикой
- Заявка на вывод
- Очередь номеров (сколько сейчас в ожидании)

### Для администраторов
- Очередь номеров (принять / отклонить)
- Заявки на вывод (подтвердить / отклонить с возвратом)
- Изменение цены за номер
- Изменение минимальной суммы вывода
- Статистика бота
- Список пользователей
- Рассылка
- Старт / Стоп бота
- Управление доступом
- Управление администраторами (только владелец)

## Быстрый запуск

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка

Скопируйте пример конфигурации:

```bash
cp .env.example .env
```

Отредактируйте `.env`:

```env
BOT_TOKEN=токен_от_BotFather
OWNER_ID=ваш_telegram_id
ADMIN_IDS=ваш_telegram_id
DB_NAME=bot.db
```

### 3. Запуск

```bash
python main.py
```

## Важные замечания

- База данных создаётся автоматически при первом запуске
- Владелец (OWNER_ID) не может быть удалён из админов
- При остановке бота обычные пользователи не могут им пользоваться, админы — могут
- Все важные данные (номера, ID, суммы) можно скопировать одним нажатием

## Требования

- Python 3.10+
- aiogram 3.14+
- aiosqlite
- python-dotenv
